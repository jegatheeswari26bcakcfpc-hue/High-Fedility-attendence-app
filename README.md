# Smart Attendance System 🎓

## Project Overview
Smart Attendance System is a simple and user-friendly application designed to manage student attendance digitally. It provides separate login and dashboard interfaces for Admin, Staff, and Students to make attendance management easier and more efficient.

## Features

-  Splash Screen with Smart Attendance branding
-  Login Page for secure access
-  Role Selection for Admin, Staff, and Student
-  Admin Dashboard to manage students, faculties, and classes
-  Staff Interface to select subjects and manage attendance
-  Attendance Submission Page to mark student attendance
-  Student Dashboard to view attendance percentage
-  Attendance Reports with monthly attendance details

## UI/UX Design

- **Design Tool:** Figma
- **Theme:** Dark Blue and Cyan
- **Design Style:** Simple, Modern, and User-Friendly
- **Platform:** Mobile Application UI Design

## Project Objective

The main objective of this project is to simplify attendance management, reduce manual work, and help administrators, staff, and students access attendance information easily.
